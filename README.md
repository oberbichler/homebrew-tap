# homebrew-tap

Homebrew tap for [@oberbichler](https://github.com/oberbichler)'s tools.

## Usage

```sh
brew install oberbichler/tap/<formula>
```

This taps the repository automatically. To tap it once and then use short names:

```sh
brew tap oberbichler/tap
brew install <formula>
```

## Formulas

| Formula | Description |
| --- | --- |
| [`dino-copy`](https://github.com/oberbichler/dino-copy) | Fast one-way directory mirror for local disks |

Prebuilt binaries are provided for macOS and Linux on both arm64 and x86_64.

## Casks

| Cask | Description |
| --- | --- |
| [`zeyt`](https://github.com/oberbichler/zeyt) | Menu bar time tracking that asks what you are working on (macOS 14+) |

```sh
brew install --cask oberbichler/tap/zeyt
```

Casks live in `Casks/` and are not generated by cargo-dist.

## Adding a formula

Formulas live in `Formula/` as `<name>.rb`. They are not written by hand: each
tool's release workflow, generated by [cargo-dist](https://github.com/axodotdev/cargo-dist),
builds the binaries and pushes an updated formula to this tap. To publish a new
tool here, set the tool's dist config to:

```toml
[workspace.metadata.dist]
installers = ["homebrew"]
tap = "oberbichler/homebrew-tap"
publish-jobs = ["homebrew"]
```

and give its release workflow a `HOMEBREW_TAP_TOKEN` secret with write access
to this repository.

## Checks

CI runs `brew test-bot` on macOS and Linux. Instead of `brew audit`, which
rejects the explicit `version` line that cargo-dist always emits, formulas are
checked with:

```sh
brew style oberbichler/tap
brew readall --aliases oberbichler/tap
```

To try a formula locally:

```sh
brew install oberbichler/tap/<name>
```
